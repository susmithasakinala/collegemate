# CollegeMate 🎓

A campus-only rental and sharing platform where verified college students can rent academic essentials from each other — safely, easily, and with full accountability.

## 🔗 Live Demo
https://susmithasakinala.github.io/collegemate

## 💡 About the Project

CollegeMate solves a real problem every college student faces — needing items like calculators, lab coats, textbooks, or sports equipment for just a short time but having to buy them at full cost.
Instead of buying, students can now rent from verified classmates on the same campus. Students who own idle items can list them and earn pocket money.

## ✨ Features

- 🔐 College email login + Google Sign-In
- 🏠 Home dashboard with featured items
- 🔍 Browse and search available items
- 📦 Upload your own items for rent
- 🛒 Cart and booking system
- 📋 Digital rental agreement per booking
- ⭐ Ratings and reviews for users and items
- ⚠️ Penalty system for misuse
- 📱 Fully responsive — works on mobile and desktop
